# COMP3123 Lab 11 - Working with Axios and Fetch API

A React application that retrieves 10 random users from `https://randomuser.me/api/?results=10` using Axios and displays them in React Bootstrap cards.

## Run locally

1. Open this folder in VS Code.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open the localhost address shown in the terminal (usually http://localhost:5173).
5. Take a screenshot after the users load.

## Lab requirements

- React project and repository: `lab11_101410018_axios_example` (replace `101410018` with your own ID).
- Packages: Axios, React Bootstrap, Bootstrap.
- `PersonList` class component uses `componentDidMount` and Axios to fetch 10 users.
- User List page with photos, user details, and optional expanded details.
